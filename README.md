# After Now / 此刻之后

**Designing What Comes Next.**

After Now is an independent creative practice exploring identity, digital experience, space, and emerging technology. This repository contains the 1.0 brand homepage built with Next.js 16 and React 19.

## Local preview

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Release checks

```bash
npm run lint
npm run build
```

Both checks pass for the current homepage.
