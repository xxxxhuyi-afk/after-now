# 合境 · 三维空间组合

这是从 `outputs/合境-三维空间组合.html` 拆出的可上传网站代码。

## 文件

- `index.html`：网页入口
- `src/styles.css`：界面样式
- `src/app.js`：Three.js 三维空间逻辑
- `src/vendor/`：Three.js 和 OrbitControls，本地自带，不依赖 CDN

## 上传方式

把整个 `hejing-3d-space` 文件夹上传到你的网站目录即可。如果你的网站后台只允许上传单个 HTML 文件，也可以继续使用原来的 `outputs/合境-三维空间组合.html`。

这个版本不需要 AI 密钥，也不需要后端接口。它是一个纯前端 3D 展厅概念工具。
